## Access to Antigravity Skills
You are co-piloting this workspace alongside Antigravity. You have full access to the Antigravity agent skills installed on this machine. 

To discover and use an Antigravity skill:
1. Search the following customization root directories to find relevant skills:
   - `C:\Users\Asus\.gemini\config\skills\`
   - `C:\Users\Asus\.gemini\config\plugins\*\skills\` (e.g., science plugins)
   - `.agents\skills\` (if any workspace-specific skills exist)
2. When you find a relevant skill directory, read the `SKILL.md` file inside it.
3. The `SKILL.md` file contains exact instructions, context, and the necessary Python scripts or commands you should run via your Bash tool to execute the skill. Follow its instructions exactly as if it were part of your own system prompt.
